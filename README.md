PPLS, or Professional Programming Language Shell, is a unique programming language that is versatile, open-source, and reliable.

PPLS is Stable and amazing for configuration, and it is easy to learn; you can make a full script in just a few lines

## Setup

If you downloaded it from the terminal using Git, it will download the root of the repository. To run it, go to the folder where it downloaded, open the directory, and look for src. Open the src directory and open the file. If you did not download it, visit https://github.com/python/cpython. Then you should be able to run the .py file after setting up Python. If you installed the MSI package, run the MSI and press Next until you see text saying the installer will install in the following folder. Select whatever directory you want; leave blank for Program Files if you don't see it pop up. Check if your machine is compatible with x86. If you do, it should drop a shortcut on your desktop. If you do, open it, and you should be in the terminal.
