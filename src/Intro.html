introduction to PPLS

Salutations, human. I made a new coding language called PPLS. To get started, I'll give you a few lists of commands.

shellprint_pt[hello world]

prints your desired text; I always go with hello world

del[C:\path\to\dir_or_file]

deletes a file or directory

mathop[2*2]printop

an example for a math equation using PPLS “2*2” prints the math which would be 4
